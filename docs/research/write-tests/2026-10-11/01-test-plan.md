# 隔离写入测试计划（2026-10-11）

## 授权与范围
用户明确允许写入测试，并选择新建测试前缀的隔离商品、批次和订单；结束停用测试商品及未用卡券、保留审计记录。此前只读报告保留不修改。

DESIGN_DECISION：本轮前缀 JSTEST261011；最多3个商品、2个批次（每批最多2张卡）、2个测试订单。先验证商品新增权限，再逐步执行；这些上限不是已执行数量。

## 顺序与恢复
1. 新建测试商品，核对新增响应与精确名称列表；仅操作本轮已确认ID。
2. 商品停用/启用验证；最终全部停用，不删除审计记录。
3. 有权限时创建多选一、多选多小批次，取消同时导出；验证码由用户完成或即时明确授权后操作，不绕过。
4. 只使用本轮测试卡；卡密不写入文件、日志或回答。先观察选品和表单，再决定订单测试。
5. 订单提交须先证明不会发送真实通知或调用真实物流，并具备专用收件测试数据；不填写猜测的手机号或真实他人地址，不修改全局通知开关。条件不足记录阻塞。
6. 最终停用测试商品及未用卡券；保留测试订单、批次和本地脱敏审计台账。停用不等同数据库回滚，已兑换权益和库存影响如实记录。

## 证据
实际写入请求与返回标记 LIVE_OBSERVED；代码标记 SOURCE_OBSERVED；未执行标记 UNKNOWN/NOT_EXECUTED。仅保存参数名、类型、允许的测试标识及脱敏结果；不保存 Cookie、Token、卡密、个人联系方式。任何权限拒绝后不绕过。
