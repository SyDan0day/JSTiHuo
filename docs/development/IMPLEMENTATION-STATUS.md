## 交付边界

业务交付为 MANUAL/MOCK；没有真实供应商契约或生产域名/密钥，不把本地模拟、Chrome 视口或自签 HTTPS 演练当作生产上线、真机或正式无障碍认证。真实证书续签、异机备份及日志告警渠道的部署、生产规模恢复压测和供应商联调由实际部署环境落实。当前备份工具单包最多 512 MiB，超限须先完善方案，不能宣称任意规模恢复。
