# 用户与运营操作指南

本系统不包含支付、分次兑换、多仓或 SKU。一卡一次兑换为一单，ONE_OF 选一种、N_OF 恰好选 N 种，每种一件。发货日期是预约出库日，不保证到货日。只有自有内容和已上架商品公开展示。

## 顾客操作

从 `/verify` 输入卡号、密码和图片验证码。未激活、过期或已兑换卡会显示真实状态，不能新兑。选品后填写省市区、详细地址和预约日期；缺少地区数据、名额不足或商品禁配时，按页面提示修正，不反复提交。

确认页只提交一次。网络结果不确定时保持页面，使用原请求恢复；不要改动地址或重新创建动作。成功后在 `/orders/result` 查看脱敏订单；离开页面后可用 `/orders/query`，填写订单号或卡号及完整收货手机查询。

查询身份默认只读。修改地址、预约日或发起售后需用该订单的原卡密和新验证码复核。待发配送单仅可在原预约日前一天上海时间 17:00 前修改；商品权益不变。`/orders/tracking` 查看本单运单与轨迹；标注 MOCK 的事件只用于模拟。

已发或完成配送单可在 `/orders/after-sales` 提交投诉或按原商品数量申请补发，每单最多一个活动案件。投诉由运营结案，补发必须批准且有可用库存；补发不逆转原单或恢复卡券。超过隐私保留期并已匿名化的订单不再按手机号查询或新开售后。

`/feedback` 提交一般咨询或反馈，需要一次性验证码。联系人被加密保存，反馈本身不能授予订单访问权限。不要把卡密写入问题描述。遇到限流按倒计时等待；刷新验证码会获取新的挑战。

## 初始运营配置

管理员从 `/admin/login` 登录，首次改密后重新登录。敏感操作先在 `/admin/security` 复核；权限不足时联系有权管理员，页面隐藏不能代替服务端权限。

1. `/admin/content` 创建自有公告、提货须知、关于与联系方式。固定 slug 为 `notice`、`guide`、`about`、`contact`；保存草稿后单独发布。未发布或撤下时公开页面显示不可用。
2. `/admin/products` 上传自有 PNG/JPEG，填写编码、名称等，保存草稿后上架。最多 9 张图，单张输入最多 5 MiB；可见不代表已有库存。
3. `/admin/inventory/documents` 新建入库单并由有审核权限人员批准；建单不会立即改库存。批准后在 `/admin/inventory` 核对 on_hand、reserved 与 available，出库不可挪用预占。对账按钮只读，不会自动补账。
4. `/admin/carriers` 建 MANUAL 或显式 MOCK 承运商。`/admin/settings` 配置日期规则、容量、停发日和默认承运商。容量不能低于已有占用；调整不改变旧订单日期。LIVE 通知/面单尚未接入真实供应商，不应在运营中当作可用能力。

## 卡券发行

在 `/admin/voucher-batches` 创建卡型版本、选择权益、数量和有效期，保存批次草稿；权益快照发行后不受商品改名或新卡型影响。单批最多 1000 张，生成依赖 worker；等待任务真正完成，不能把排队状态当作成功。

有发行权限且近期复核后下载短期卡密文件，通过安全渠道完成印刷或交付，随后封存并按需要激活。封存与 TTL 后不再允许下载原密码；文件目录不提供公开链接。卡券列表只显示元数据。密码重置会使旧密码和相关旧会话失效，必须重新安全交付。

卡券有效期、激活、软删等操作比较版本。遇到版本冲突先刷新；网络结果不确定只用原动作恢复。取消订单释放预占及当日名额，但不会返还卡券的已消费权益。

## 履约与售后

后台订单列表按状态分页，详情展示脱敏资料；查看完整收件信息需权限和填写原因，并留审计。预约日到达后在发货页面填写承运商和全单运单；发货将预占转实扣。同一原单只能有一个主运单。

自动面单仅在已配置支持的适配器下可用。READY 结果需核对承运商、单号与订单版本后确认发货；UNKNOWN 必须先核对供应商结果，不能重新创建另一张面单。MANUAL 不会自动签收；人工完成需明确原因。MOCK 自动轨迹始终标注模拟。

到店订单在 `/admin/pickups` 核验原卡密及完整商品集合后核销，直接完成，不占配送日额度、不生成配送运单。

`/admin/after-sales` 审核投诉或补发。批准补发只扣可用库存，不挪用其他订单预占；按案件登记唯一补发运单，实际签收后关单。案件处置不回滚原发记录或卡券消费。

## CSV、报表与任务

`/admin/files` 上传 UTF-8 CSV（可有 BOM），最多 5 MiB、1000 行。先上传加密暂存，再创建预检任务；预检无错误后显式确认。错误只显示逻辑行号、字段和稳定错误码，不回显卡密或原文件。

|导入类型|固定表头|处理方式|
|---|---|---|
|卡券|`code,secret,valid_from,valid_until`|仅指定草稿批次；数量和密码格式须匹配；日期为带时区 RFC3339；整批原子应用|
|运单|`order_no,carrier_code,tracking_no,expected_version`|预检订单版本及承运商；逐行发货，成功行不重复，失败行保留可追踪结果|

卡密 CSV 只经授权安全渠道准备和传递，不粘贴到日志或工单。任务详情页刷新权威状态；不要重复创建同文件任务绕过确认。报表只含脱敏白名单字段，限制 10 MiB/10 万行，并做 CSV 公式转义。到期后不能下载，文件物理清理由 worker 完成。

## 权限、审计及异常恢复

`/admin/admins` 和 `/admin/roles` 管理账户、角色及权限，修改需要近期复核；不能授予超出自己上限的权限，也不能移除最后一个完整管理员。改权、禁用或改密会撤销相关会话。`/admin/audit` 只读查询审计；不展示敏感原文。`/admin/regions` 为版本化地区只读目录，公开二维码在 `/admin/tools/qr` 本地生成，仅允许本站固定公开入口。

通知页面区分 FAILED、SUPPRESSED、UNKNOWN 等真实状态：DISABLED 不发送；明确失败可按规则重试，未知结果需复核和外部证据。不要通过直接改库绕过状态机。操作失败时保存页面 request_id 和对象 ID，联系运维，勿提交卡密、Cookie 或完整收货资料。

数据库恢复、初始化、任意命令和秘密管理均只在受控运维 CLI 中进行，参见 [运维手册](operations.md)。
